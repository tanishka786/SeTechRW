# Birla Carbon Demo Product Data

These records are FICTIONAL demo data created for the local QR/barcode warehouse POC.
They are not representations of actual Birla Carbon products, batches, prices,
manufacturing records, or inventory.

Files:
- demo_products.py  -> copy/paste-ready Python dictionaries
- demo_products.json -> JSON/MongoDB seed source
- demo_products.csv -> spreadsheet/import source

Product references/barcodes:
226587 through 226606

Use these records with the local QR/barcode application. The website field points
to the official Birla Carbon website for demonstration purposes.
